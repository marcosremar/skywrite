## Findings considered and rejected

Recorded so they are not re-audited next run. Each was opened and verified against
the live code.

- **IDOR on `PATCH /api/projects/:id`** — false positive. `projects.ts:110`
  `findUnique` is only reached after `updateMany({where:{id,userId}})` returns
  count > 0, which already proves ownership.
- **IDOR on `GET .../build/:buildId/pdf`** — false positive. `build.ts:139` checks
  `project.userId` and `:143` checks `build.projectId === id`; access is transitively gated.
- **Content-Disposition header injection** (`build.ts:153`, `report.ts`, `auth.ts`) —
  false positive. Filename is sanitized with `replace(/[^a-zA-Z0-9-_]+/g,"_")`,
  which strips CR/LF/quotes; no CRLF survives.
- **`tw-animate-css` is a dead dependency** — false positive. It provides the
  `animate-in`/`animate-out`/`fade-in`/`zoom-in`/`slide-in` classes used by 5 Radix
  UI components (alert-dialog, dialog, select, dropdown-menu, context-menu).
  Removing it would break enter/exit animations.
- **Weak JWT secret allowed in dev** (`auth.ts:5`) — false positive. The guard
  `process.env.NODE_ENV !== "test" && JWT_SECRET.length < 16` throws in all
  non-test envs (including undefined/dev/prod). Only the test env uses a default.
- **File-switch autosave race corrupts content** (`EditorLayout.tsx`) — mitigated.
  `flushSave` guards with `loadedFileRef.current !== file.id`, so it never writes
  one file's content to another's path during a switch.
- **IPv4-mapped-IPv6 SSRF bypass** (`ssrf.ts`) — already fixed (hex-form decoding at `ssrf.ts:21-26`).
- **`/api/templates` lacks auth** — by design. Public template catalog read from
  disk; no PII; SPEC marks it unauthenticated.
- **Prompt injection via user question/content** (`research.ts`) — downgraded. The
  real third-party vector (paper full-text) is already delimited with `<fonte>`
  tags **and** stripped of nested tags (`stripFonteTag`); the user attacking their
  own LLM session is not a security boundary. Optional defense-in-depth only.
- **Double query in `PATCH` project** (`projects.ts:103-110`) — negligible.
  `updateMany` + `findUnique` is the idiomatic Prisma pattern for an ownership-gated
  update; not worth a plan.
- **God files** `MarkdownEditor.tsx` (1510 LOC), `AIAdvisor.tsx` (1187 LOC) — real
  maintainability cost but L-effort, MED-risk refactors with no behavioral bug; not
  planned now. Revisit if these files become change hotspots.
- **No linter/formatter** — real DX gap (no eslint/prettier/biome config; CI has no
  lint gate). Worth a Biome setup later; not selected for this batch.
- **CI installs deps 3× uncached** (`.github/workflows/ci.yml`) — minor CI speedup
  via a `~/.bun` cache; not selected for this batch.
- **Minor robustness nits**: `storage.ts:48` `res.Body!` non-null assertion;
  `ai-gateway.ts` empty-content passthrough; `files.ts` rename check-then-act (P2002
  is caught anyway). Low leverage; not planned.
